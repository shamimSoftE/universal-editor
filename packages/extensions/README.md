# @shamimsofte/universal-editor-extensions

[![npm version](https://img.shields.io/npm/v/@shamimsofte/universal-editor-extensions.svg?style=flat-square)](https://www.npmjs.com/package/@shamimsofte/universal-editor-extensions)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)](https://opensource.org/licenses/MIT)

Official Extensions Registry for **Universal Rich Text Editor**. Provides plugins for AI assistance, video embeds, table manipulation, syntax highlighting, and slash commands.

---

## 📦 Installation

```bash
npm install @shamimsofte/universal-editor-extensions @shamimsofte/universal-editor-core
```
